ObjectPlanet's TabbedPanel
This java based tabbed panel component enables you to add several components in one panel with a named tab for each component. The user can switch between the components by clicking the tabs.

Each tab can be detached into it's own top-level application window by right-clicking an active tab. This enables the user to display several of the components at the same time as well as resizing them individually.

You can also control the colors of each tab as well as fonts and font sizes. The tabs can be displayed at the top, bottom, left, or right side of the components.

How to use
To use the tabbed panel in your java application, import the com.objectplanet.gui.TabbedPanel.jar file in your development environment, or add the same file or the com/objectplant/gui directory to your CLASSPATH environment variable.

Then you can import the class and create an instance like this 

import java.awt.*;
import com.objectplanet.gui.TabbedPanel;

public class TabbedPanelDemo {
   public static void main(String[] argv) {
      TabbedPanel tabbed = new TabbedPanel();
  		tabbed.add("monday", new Button("monday"));
		tabbed.add("tuesday", new Button("tuesday"));
		tabbed.add("wednesday", new Button("wednesday"));
		tabbed.add("thursday", new Button("thursday"));
		tabbed.add("friday", new Button("friday"));
		tabbed.add("saturday", new Button("saturday"));
		tabbed.add("sunday", new Button("sunday"));

      Frame f = new Frame();
      f.add("Center", tabbed);
      f.setSize(400,30);
      f.show();
   }
}


Two versions
The tabbed panel component comes in two versions, one compatible with JDK 1.1, supported by Netscape 4.06 or newer and Internet Explorer or newer. And one compatible with JDK 1.02, supported by Netscape 3 and Internet Explorer 3 or later.

The class files for JDK 1.1 version is found in the com.objectplanet.gui.TabbedPanel.jar archive file. The class files for the JDK 1.02 version is found in the com\objectplanet\gui102 directory.

The package name for the JDK 1.1 version is com.objectplanet.gui and com.objectplanet.gui102 for the JDK 1.02 version
